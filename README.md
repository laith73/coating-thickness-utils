# coating-thickness-utils

This repo contains MATLAB functions for designing dielectric applicators and estimating thin dielectric coating thickness from open-ended circular waveguide reflection measurements. These functions implement the methods described in the paper "Microwave Thickness Measurement of Thin Coatings on Conductive Materials Using an Open-Ended Circular Waveguide Probe"
